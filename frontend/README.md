# Invoice Audit Intelligence — Frontend Workstation

This directory contains the Next.js + TypeScript + Tailwind CSS web application for the Invoice Audit Intelligence project.

For full project documentation, architecture details, audit engine documentation, and setup instructions, please refer to the main [Root README](../README.md).

## Quick Start (Frontend)

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build production bundle
npm run build
```
